# Роли администраторов

В панели предусмотрены три уровня доступа.

РольВозможностиownerполный доступ, настройки, бэкапы, ноды, админы и пользователиadminуправление пользователями, просмотр нод, создание sellersellerтолько собственные пользователи

## Ограничения

- owner нельзя удалить или лишить доступа действиями другого администратора;

- owner может создавать admin и seller;

- admin может создавать только seller;

- seller не видит чужих пользователей и не управляет администраторами;

- бэкапы и брендинг доступны только owner;

- создание, импорт и удаление нод доступны только owner;

- локальную ноду удалить нельзя.

Для менеджера продаж используйте seller. Роль admin выдавайте только сотрудникам, которым действительно нужен широкий доступ к пользователям и серверной информации.
